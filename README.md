# Văn phòng 68 Phan Đăng Lưu: phối cảnh cuộn

Trang phối cảnh cuộn 3D dựng thử hai tầng văn phòng (tầng 11, 12) từ mặt bằng kiến trúc tầng 11.

Xem: https://andyluu98.github.io/van-phong-68-phan-dang-luu/

- Tầng 12 lặp lại mặt bằng tầng 11; chiều cao tầng 3600 là giả định.
- Mặt ngoài kính, sảnh thang máy, WC dựng gần đúng theo ảnh thực tế tòa nhà. Nội thất văn phòng, cảnh quanh lô là minh họa.
- Mô hình để trình bày, không thay hồ sơ thiết kế.

Dựng bằng plugin [vn-phoi-canh-cuon](https://github.com/andyluu98/vn-phoi-canh-cuon). Đơn vị: Công ty Ces AI. Vân vật liệu, bầu trời: Poly Haven (CC0).
